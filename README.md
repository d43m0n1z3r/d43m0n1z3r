<summary><b>📡 bconn</b> — bluetooth companion for linux desktops <code>★ flagship op</code></summary>

A tray-first Bluetooth companion: one-click connect, auto-reconnect,
PipeWire-aware audio routing, and diagnostics that tell you the fix —
not just `org.bluez.Error.Failed`.

```bash
git clone https://github.com/d43m0n1z3r/bconn && cd bconn
pip install -e . && bconn doctor
```

**Stack:** `python` `dbus-next` `pydbus` `gi/gtk3` `pipewire` `systemd --user`
